# Sample Data Descriptions

## Sales Data (`sample_sales_data.csv`)
- **Purpose**: E-commerce sales analysis
- **Fields**: Date, Product, Category, Sales Amount, Quantity, Customer ID, Region
- **Describes**: Revenue, seasonal sales patterns, product performance, and regional sales.

## E-commerce Data (`sample_ecommerce_data.csv`)
- **Purpose**: Online store analysis
- **Fields**: Order ID, Customer details, Product information, Payment data, Shipping data
- **Describes**: Customer purchases, order activity, payments, shipping, and store performance.

## Employee Data (`sample_employee_data.csv`)
- **Purpose**: Human resources analysis
- **Fields**: Employee ID, Name, Department, Salary, Performance metrics
- **Describes**: Employee roles, departments, salaries, and performance.

## Marketing Data (`sample_marketing_data.csv`)
- **Purpose**: Marketing campaign analysis
- **Fields**: Campaign ID, Channel, Budget, Impressions, Clicks, Conversions
- **Describes**: Campaign reach, advertising costs, engagement, conversions, and channel performance.

## Financial Data (`sample_financial_data.csv`)
- **Purpose**: Financial analysis
- **Fields**: Transaction ID, Account, Amount, Category, Date, Balance
- **Describes**: Transactions, account activity, income or expenses, categories, and balances.

## Inventory Data (`sample_inventory_data.csv`)
- **Purpose**: Inventory and supply chain analysis
- **Fields**: Product ID, Name, Category, Stock levels, Supplier information
- **Describes**: Product stock, inventory levels, categories, suppliers, and replenishment needs.

## Customer Data (`sample_customer_data.csv`)
- **Purpose**: Customer relationship analysis
- **Fields**: Customer demographics, purchase history, preferences
- **Describes**: Customer profiles, purchasing behavior, preferences, segmentation, and retention.

## Survey Data (`sample_survey_data.csv`)
- **Purpose**: Survey and feedback analysis
- **Fields**: Survey responses, Ratings, Demographics, Feedback categories
- **Describes**: Customer opinions, satisfaction ratings, demographic patterns, and feedback themes.

## Website Analytics (`sample_website_analytics_data.csv`)
- **Purpose**: Website traffic analysis
- **Fields**: Sessions, Page views, Traffic sources, Conversions
- **Describes**: Website visits, page activity, traffic channels, user behavior, and conversions.

## Project Management Data (`sample_project_data.csv`)
- **Purpose**: Project tracking and portfolio analysis
- **Fields**: Project details, Timelines, Budgets, Team information, Status
- **Describes**: Project schedules, budgets, teams, progress, and project status.

## IoT Sensor Data (`sample_iot_sensor_data.csv`)
- **Purpose**: IoT monitoring and sensor analysis
- **Fields**: Sensor readings, Timestamps, Device status, Location data
- **Describes**: Sensor measurements, device activity, locations, environmental conditions, and anomalies.

## Missing Values Scenario (`data_quality_missing_values.csv`)
- **Purpose**: Missing-data analysis
- **Fields**: Customer ID, Customer type, Age, City, Lifetime value, Last purchase date
- **Describes**: Blank customer attributes and incomplete records for missing-value detection.

## Duplicate Records Scenario (`data_quality_duplicates.csv`)
- **Purpose**: Duplicate-record analysis
- **Fields**: Order ID, Order date, Product, Region, Quantity, Sales amount
- **Describes**: Repeated orders for testing duplicate detection and data deduplication.

## Invalid Values Scenario (`data_quality_invalid_values.csv`)
- **Purpose**: Invalid-data and outlier analysis
- **Fields**: Sensor ID, Timestamp, Temperature, Humidity, Status, Battery level
- **Describes**: Invalid dates, non-numeric values, unknown statuses, and out-of-range measurements.
